About the Project

Objective

To demonstrate how programming concepts can be used in creative computing by building an application that generates unique digital artwork using code.

Features

  • Three generative art styles: Geometric, Flowing and Fractal
  • Five colour palettes based on different moods
  • Controls for complexity and symmetry
  • Surprise Me option to generate random combinations
  • Save artwork in the browser and download it as a PNG

Programming Concepts Used

  • Randomisation: creates varied shapes, colours and patterns
  • Loops: draw repeated shapes and flowing lines
  • Recursion: creates branching fractal patterns
  • Trigonometry: uses sine and cosine to position and draw shapes
  • DOM Events: handle user interactions and controls
  • LocalStorage: saves artwork in the browser

Technologies

HTML5, CSS3 & JavaScript. No external libraries are used.
